## 2026-11-14

- 语音转码与模型提示：微信语音原件是 SILK（实测 9.1 kbps，10 秒 11 KB），WAV 是不压缩 PCM，所以体积必然大很多。输出从 24kHz 改为 16kHz（识别本来就重采样到 16k，播放不受影响），从 42.4 倍降到 28.3 倍，实测 11405 字节转出 322604 字节、16000Hz 单声道 16bit。同时把「模型缺失」从静默改为显式：结果里出现 warnings 提示与 voice_model_missing 计数，告知模型应放到 decrypted/models/sensevoice/。提交 6610b82。
- 文件与媒体原件提取：文件类消息（PDF、表格、压缩包等）读取时自动复制到本进程 exports/run-*/files/，media.path 返回副本路径、source_path 保留微信原路径，单文件限 100MB、单次最多 20 个。语音转写同时返回原始音频，extract_media 时存成 .silk；视频新增 resolve_video 定位本地 mp4，可存原件。实测某群 14 个文件全部复制成功，合计 45.5MB。提交 895ac5c。
- 同时修两个既有 bug：一是 msg/file 下的文件查找被错误绑定会话哈希，会话 ID 为空时直接跳过，导致大量文件 exists=False；二是 media_files 只读 WECHAT_FILES_DIR 没有兜底，CLI 或直接调 service 时全部解析失败，改用 config.get_wechat_files_dir()。修复后同一文件从 exists=False 变为 True。
- 联系人性别可解析：contact.extra_buffer 的 protobuf 字段 2 是性别枚举（1 男、2 女、0 未设置）。用两张已知性别的截图对照验证：好友一男一女结果均一致，地区与添加时间同时对上。list_entities 与 relations(group_members) 都返回 gender，群成员另补 region。覆盖率：好友 100% 有资料包，群成员与非好友约 78%；全库 26718 条资料中男 711、女 860，其余未设置。本地没缓存资料卡的非好友仍为空。提交 72b21ea。
