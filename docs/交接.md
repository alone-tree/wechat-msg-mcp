## 接手须知

| 场景 | 做法 |
|---|---|
| 想用工具 | 直接 mcp_load，不需要跑脚本、不需要起服务 |
| 想要最新数据 | 等 TTL（60 秒）自动刷，或调 system(action="sync") |
| 想看是否刷新了 | 每个查询结果的 refresh 字段 |
| 想改刷新频率 | 环境变量 WECHAT_REFRESH_TTL；0 每次刷，负数关闭 |
| 换机器 | 改注册表 env 里的 WECHAT_FILES_DIR，或设同名环境变量 |
| 只想刷新数据 | uv run python scripts\quick_decrypt.py（增量，--full 全量） |
