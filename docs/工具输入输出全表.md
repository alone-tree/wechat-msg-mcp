# 工具输入输出全表

2026-11-14 逐条实测。用具名参数与真实数据各调一次，把返回结构原样记下。设计口径仍然以 AGENTS.md 与 docs/总体设计.md 为准，本文只记录「实际长什么样」。

## 0 前置约定

七个工具：system、list_entities、get_messages、relations、search、list_moments、list_favorites。

所有工具共用四件事：

| 约定 | 行为 |
|---|---|
| 刷新 | 每个查询工具调用完会自动按 TTL（默认 60 秒）增量刷新，结果里带 refresh 字段 |
| 落盘 | 六个查询工具都有 output、output_dir、format 三件套；超过 200 行或 80000 字符自动落盘，只留前 3 条预览 |
| 媒体 | 只有 get_messages 处理媒体（图片内联、语音转写、文件复制） |
| 报错 | 取值写错不给结果，返回 error 与 valid；但 types、sort 两项例外，见第七节 |

## 1 通用输出字段

| 字段 | 何时出现 | 含义 |
|---|---|---|
| refresh | 六个查询工具，以及 system 的 status | 本次刷新情况，两种分支字段不同，见下表 |
| data_cutoff | 全部 | 该数据面最后一次写入时间，不是消息时间 |
| self | get_messages、system | 账号主人：id、nickname、alias、note |
| senders | get_messages 有消息时 | 本条结果里出现过的发送者：wxid 到 name/alias/nickname/friend 的映射 |
| unresolved | get_messages、list_entities | 目标名解析失败时的候选列表 |
| hints | get_messages，按内容触发 | media.url 可打开、转账金额来源、红包需拆开等提示 |
| warnings | get_messages，按条件触发 | 语音模型缺失、图片无本地文件等 |
| media_missing | get_messages，有缺失媒体时 | 按原因计数，如 {"no_local_image": 3} |
| export | output=file | 落盘信息：exported、path、files、rows、bytes |
| auto_export | inline 模式下超阈值 | 同 export，另加 reason |
| file_export | 消息里有可复制的文件 | exported、skipped、dir、bytes |
| media_inline | 有内联图片时 | inlined、inlined_bytes、not_inlined、image_budget_bytes，可带 note |
| media_extract | 传了 extract_media | saved、dir，视频另给 video 子对象 |

refresh 字段：

| 分支 | 字段 |
|---|---|
| 实际刷新 | refreshed、skipped、changed_dbs、failed、failed_detail、shadow、seconds、ttl_left、index |
| TTL 内跳过 | refreshed=false、skipped=ttl、ttl_left、changed_dbs、failed、failed_detail、shadow |
| 关闭刷新 | refreshed=false、skipped=disabled |

## 2 system

输入：

| 参数 | 类型 | 默认 | 取值 | 行为 |
|---|---|---|---|---|
| action | str | start | start / status / sync | start 给说明书与状态；status 只看新鲜度；sync 立即刷新；写错返回 error 与 valid |
| force | bool | true | 真/假 | 只对 sync 生效，true 忽略 TTL |

输出三种：

| action | 顶层字段 |
|---|---|
| start | server、intro、self、guide、status{state, data_cutoff, message_dbs, contacts, groups, index{rows, exists, size_mb}}、next |
| status | state、data_cutoff、root、message_dbs、contacts、groups、files{库名: 时间}、index{rows, exists, size_mb}、refresh{ttl_seconds, ttl_left, last{...}} |
| sync | 与 refresh 相同：refreshed、skipped、changed_dbs、failed、failed_detail、shadow、seconds、ttl_left、index |

## 4 get_messages

输入：

| 参数 | 类型 | 默认 | 取值 | 行为 |
|---|---|---|---|---|
| targets | list | null | 会话名或 id，可混 | 留空且无日期时只查最近 30 天，返回 default_window_days=30 |
| sender | str | 空 | wxid / 备注 / 昵称 | 只留此人发的 |
| start_date / end_date | str | 空 | YYYY-MM-DD | 含当天 |
| types | list | null | 见下 | 不校验，写错静默 0 条 |
| keyword | str | 空 | 任意 | 正文包含 |
| order | str | desc | desc / asc | 数组顺序随之变化 |
| limit | int | 200 | 1 到 1000 | 超过 1000 按 1000 算 |
| cursor | str | 空 | next_cursor | 翻页游标 |
| output / output_dir / format | | inline / 空 / csv | file 时落盘 | format 默认是 csv，与其它工具不同 |
| include_media | bool | true | 真/假 | 返回行数超过 50 时自动跳过媒体提取 |
| extract_media | str | 空 | 空 / auto / 绝对目录 | 把图片、语音、视频原件另存 |

types 实测有效值：text、image、voice、video、emoticon、location、file、link、mini_program、quote、chat_record、channels、system、revoked，以及未写进文档的 app:transfer、app:red_packet。

输出：

| 字段 | 含义 |
|---|---|
| total | 命中总数，注意是游标过滤前统计的 |
| returned / has_more / next_cursor | 本页条数与翻页 |
| default_window_days | 默认窗口天数，0 表示按下界截取 |
| self / senders | 账号主人与发送者表 |
| data_cutoff | 消息库最后写入时间 |
| messages[] | 见下 |
| unresolved | 目标解析不到时的候选 |
| refresh | 通用 |
| hints / warnings / media_missing / file_export | 条件字段 |

message 字段：

| 字段 | 说明 |
|---|---|
| local_id、time、local_type | 库内主键、时间、原始类型整数 |
| direction | in / out |
| type / subtype | type 为 text、image、voice、video、emoticon、app、system 等；app 再给 subtype |
| sender_name | 自己发的显示「我」，别人给备注优先的名字 |
| chat_id / chat_name | 会话 id 与显示名（无名群等于 id） |
| text | 正文；媒体消息这里是标题或空 |
| media | 见下表，非媒体为 null |

media 按 kind 的字段：

| kind | 字段 |
|---|---|
| image | kind、source（dat / thumb / cache）、bytes、inlined、note、tiles、path |
| emoticon | kind、source、bytes、inlined |
| video | kind、duration、source=cover、bytes、inlined、video_path、video_exists、video_size |
| voice | kind、duration、transcribed，消息行另带 voice_text |
| file | kind、name、size、path（副本）、exists、source_path、exported、missing_reason、note |
| link | kind、url、title、desc、openable |
| transfer | kind、amount、des、pay_sub_type |
| red_packet | kind、url、amount（恒 null）、des、note |
| mini_program / channels | kind、url、title、openable |
| quote | 无 media（正文里带引用文） |
| system | 无 media |

拿不到媒体时统一带 missing_reason：no_local_image、no_local_file、no_image_key、decode_failed、voice_model_missing、no_audio、cover_missing、not_requested、too_many_rows、budget_exhausted。

## 9 硬约束一览

| 常量 | 值 | 影响 |
|---|---|---|
| 自动落盘阈值 | 200 行或 80000 字符 | 触发后只留 3 条预览 |
| 响应体上限 | 10MB | 内联图片预算 6MB 原始字节，超了改落盘 |
| 单文件复制上限 | 100MB、单次 20 个 | 文件消息自动复制到 exports |
| 媒体提取跳过线 | 返回行数超过 50 | include_media 自动不提取 |
| 多目标单会话上限 | 50 条（per_target_limit，未暴露） | 批量拉多群时每个群最多 50 |
| 消息 limit 上限 | 1000 | 超过按 1000 |
| 默认时间窗 | 30 天 | 无 targets 且无日期时生效 |
| 长截图切段 | 单段 1600 高、重叠 80、最多 10 段 | 长宽比超过 3 才切 |

## 10 实测发现的不一致

| 项 | 现状 | 影响 |
|---|---|---|
| types 不校验 | 写 nonsense 或 transfer 都返回 0 条且不报错；要过滤转账得写 app:transfer | 静默空结果，难排查 |
