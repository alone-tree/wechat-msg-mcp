# 工具输入输出全表

2026-11-14 逐条实测，对齐提交 9dd2156（消息模型与输出规范落地）、b077e6b（渲染微调）、668bae0 与 7fb4fe0（口径纠正与补测）。实测方式：`.venv/Scripts/python.exe` 直接调 `src.service.Service(auto_refresh=False)`，以及 `python -m src.cli` 各子命令。示例一律占位（某群、某人、wxid_xxx、12345678@chatroom、2026-01-01），不写真实群名、wxid、金额与聊天正文。设计口径见 docs/重构方案-消息模型与输出规范-2026-11-14.md，本文只记录实际长什么样。

## 0 前置约定

七个工具：system、list_entities、get_messages、relations、search、list_moments、list_favorites。

| 约定 | 行为 | 证据 |
|---|---|---|
| 刷新 | 六个查询工具调用后自动按 TTL 增量刷新（默认 60 秒），结果带 refresh；system 的 status 带 refresh，sync 直接返回刷新结果本身 | service.py:22-35、freshness.py:18 |
| 数据截止 | 每个信封顶层 data_until，按数据面取库文件 mtime：消息取 message 分库，朋友圈取 sns，收藏取 favorite，会话取 session 与 contact | db/locator.py:107-124 |
| 分页 | 统一 total、returned、has_more、next。get_messages 的 next 是游标字符串，传回 cursor；list_entities、search、list_moments、list_favorites、CLI groups 的 next 是 offset 数值，传回 offset；relations 的 next 恒为 null | messages.py:717-724、entities.py:479-500、search.py:118、relations.py:119 |
| 详细度 | get_messages 与 list_entities 支持 lite/full/raw（list_entities 只区分 lite 与其它）；MCP 默认 lite，CLI 默认 full | mcp_tools.py:355、401；cli.py:312 |
| 落盘 | 六个查询工具都有 output、output_dir、format；inline 结果超过 200 行或 80000 字符自动落盘，列表只留 3 条预览 | mcp_tools.py:12-13、68-78 |
| 媒体 | 只有 get_messages 处理媒体（图片内联、语音转写、文件复制） | mcp_tools.py:452-494 |
| 报错 | 新式：ok=false 加 error{code, message, candidates 或 unknown}；另有若干旧式 error 字符串未迁移，见第 10 节 | messages.py:546-549 |

## 1 通用输出字段

| 字段 | 出现位置 | 含义 |
|---|---|---|
| ok | 大多数查询信封 | true 为成功；system 的 status/sync 与部分旧式报错没有这个字段 |
| refresh | 六个查询工具、system 的 status | 本次刷新情况，见下表 |
| data_until | 全部查询 | 该数据面最后写入时间，不是最新消息时间 |
| self | get_messages、system 的 start | {id, nickname, alias, note}，id 是本机 wxid |
| senders | get_messages 的 full 与 raw | 本页发送者表：wxid 到 {name, nickname, alias, friend}；系统消息不进表 |
| unresolved | get_messages、relations、CLI groups | 目标名解析失败或没有可查分表，给候选 |
| hints | get_messages，按内容触发 | media.url 可打开、转账金额来源、红包需拆开后才可见 |
| warnings | get_messages、CLI groups | 截断点名、目标未解析、媒体超行数、语音模型缺失 |
| media_missing | get_messages，有失败媒体时 | 按 missing_reason 计数 |
| file_export | get_messages，有文件消息时 | exported、skipped、dir、bytes |
| media_inline | get_messages，有内联图片时 | inlined、inlined_bytes、not_inlined、image_budget_bytes，溢出时另给 note |
| media_extract | 传了 extract_media | saved、dir；视频另给 video{exported, skipped, dir} |
| export | output=file | exported、path、files、rows、bytes、format、columns、is_partial、pages |
| auto_export | inline 超阈值 | 同 export 再加 reason，列表已裁成 3 条 |

refresh 三种分支：

| 分支 | 字段 |
|---|---|
| 实际刷新 | refreshed=true、skipped 为空串、changed_dbs、failed、failed_detail、shadow、seconds、ttl_left、index |
| TTL 内跳过 | refreshed=false、skipped=ttl、ttl_left、changed_dbs、failed、failed_detail、shadow |
| 其它跳过 | refreshed=false、skipped=disabled / locked / no_source / no_keys / error，可带 error 文本 |

错误结构，新式：

| code | 工具 | 附带 |
|---|---|---|
| unknown_scope | list_entities | candidates=["session","contact","group","all"] 与 hint |
| bad_detail | get_messages | candidates=["lite","full","raw"] |
| unknown_types | get_messages | unknown 列表与 candidates（合法类型全表） |
| no_valid_members | CLI groups | unresolved |
| no_contact_db | CLI groups | 无 |

旧式错误（只有 error 字符串，没有 ok=false）：system 的 action 写错、search 的 scope 写错、list_favorites 的 type 写错，都另给 valid；relations 的 kind 写错只给 error；朋友圈与收藏缺库、relations 缺索引或没有分表，也只给 error。

## 2 system

输入：

| 参数 | 类型 | 默认 | 取值 | 行为 |
|---|---|---|---|---|
| action | str | start | start / status / sync | start 给说明书与状态；status 只看新鲜度；sync 立即刷新；写错返回旧式 error 与 valid |
| force | bool | true | 真/假 | 只对 sync 生效，true 忽略 TTL |

输出三态：

| action | 顶层字段 |
|---|---|
| start | server、intro、self{id,nickname,alias,note}、guide（长字符串）、status{state,data_until,message_dbs,contacts,groups,index_rows,index_size_mb}、next |
| status | state、data_until、root、message_dbs、contacts、groups、files{库文件名: 时间}、index{rows,exists,size_mb}、refresh{ttl_seconds,ttl_left,last{...}}；没有 ok |
| sync | refreshed、skipped、changed_dbs、failed、failed_detail、shadow、seconds、ttl_left、index；没有 ok |

实测 status（数值与库名按本机，时间用占位）：

```json
{"state":"ok","data_until":"2026-11-14 16:20:00","root":".../decrypted","message_dbs":12,"contacts":32100,"groups":771,
 "files":{"contact.db":"2026-11-14 16:19:00","message_0.db":"2026-11-14 16:20:00","session.db":"2026-11-14 16:20:00"},
 "index":{"rows":1350000,"exists":true,"size_mb":408.7},
 "refresh":{"ttl_seconds":60,"ttl_left":12.3,"last":{"changed":[],"failed":[],"failed_detail":{},"shadow":[]}}}
```

注意：start 里的 guide 是完整说明书全文（guide.py:19-115），不是短引导；CLI 的 status 永远输出缩进 JSON，`--json` 对它不生效（cli.py:206-208）。

## 3 list_entities

输入：

| 参数 | 类型 | 默认 | 取值 | 行为 |
|---|---|---|---|---|
| scope | str | session | session / contact / group / all | 写错返回 ok=false、candidates 与 hint |
| keyword | str | 空 | 任意 | 子串匹配 name、nickname、id、remark |
| since_days | int | 0 | 0 起 | 只留该天数内有会话记录的实体，按会话表 last_time 过滤 |
| only_group | bool | false | 真/假 | 只看群 |
| only_unread | bool | false | 真/假 | 只看 unread 大于 0 |
| min_members / max_members | int | 0 | 0 起 | 群成员数闭区间，0 为不限；max 只对 member_count 非 0 的群生效 |
| sort | str | last_time | last_time / members / name | 写错静默按 last_time，不报错 |
| limit | int | 100 | 正整数 | 无上限钳制，传大数即全量 |
| offset | int | 0 | 0 起 | 与 next 配合 |
| detail | str | lite | lite 或其它 | 不校验：除 lite 外任何值都按 full 处理 |
| output / output_dir / format | | inline / 空 / json | file 时落盘 | format 支持 csv/json/ndjson/md/text/html |

输出：

| 字段 | 含义 |
|---|---|
| ok、detail、scope、data_until | 基本信封 |
| total、returned、has_more、next | 分页，next 是 offset 数值或 null |
| entities[] | 见下 |

entity 字段：

| 字段 | 群 | 人 | lite 是否保留 |
|---|---|---|---|
| id | 有（xxx@chatroom） | 有（wxid_xxx） | 是 |
| kind | group | person | 是 |
| name、name_source | 有 | 有 | 是 |
| remark / nickname / alias | 有 | 有 | 是 |
| is_friend | false | 真/假/null | 是 |
| member_count / owner_id / owner_name | 有 / 可空 / 有 | null / null / 空串 | 是 |
| last_active_at / last_message / unread | 有 | 有 | 是 |
| members_digest | name_source=members 时给，最多 6 个昵称 | 无 | 是 |
| region / gender / add_time / notice | 空 / 空 / 空 / 有 | 有（可能空） | 否，仅 full |

name_source 取值（实测分布：remark 50、nickname 563、members 159、fallback 4）：

| 情况 | name | name_source |
|---|---|---|
| 有备注 | 备注 | remark |
| 有昵称 | 昵称 | nickname |
| 都没有但能取到成员 | 前 3 个非自己成员昵称加「等 N 人」 | members |
| 成员也取不到 | 「群聊」 | fallback |

实测（群，lite）：

```json
{"id":"12345678@chatroom","kind":"group","name":"某群","name_source":"nickname","remark":"","nickname":"某群","alias":"",
 "is_friend":false,"member_count":42,"owner_id":"wxid_xxx","owner_name":"某人","last_active_at":"2026-11-14 10:00:00",
 "last_message":"……","unread":3}
```

实测（无名群，lite，带 members_digest）：

```json
{"id":"12345678@chatroom","kind":"group","name":"某甲、某乙、某丙等42人","name_source":"members","members_digest":["某甲","某乙","某丙"],"member_count":42}
```

注意：scope=all 等于全部联系人与群（来自 contact 表），不等于会话表全集；只在 session 表里出现、contact 表没有的会话不会出现在 all 里，但会出现在 session 里。

## 4 get_messages

输入：

| 参数 | 类型 | 默认 | 取值 | 行为 |
|---|---|---|---|---|
| targets | list | null | 会话名或 id，可混人、群 | 每个目标取 resolve 的第一个候选，歧义不报错；留空且无日期时只查最近 30 天，返回 default_window_days=30 |
| sender | str | 空 | wxid / 显示名 | 对 sender_id 与 from 做包含匹配；都匹配不到时回 warnings 说明匹配方式 |
| start_date / end_date | str | 空 | YYYY-MM-DD | 含首尾当天（end 加 86399 秒） |
| types | list | null | 见下 18 个合法值 | 写错返回 ok=false、unknown 与 candidates，不静默返回空 |
| keyword | str | 空 | 任意 | 只匹配 text 字段，不匹配 raw |
| order | str | desc | desc / asc | 写错静默按 desc |
| limit | int | 200 | 1 到 1000 | 超过 1000 按 1000 |
| cursor | str | 空 | 上一页的 next | 非法游标静默当第一页 |
| detail | str | lite | lite / full / raw | 写错返回 ok=false 与 candidates |
| per_target_limit | int | 0 | 0 起 | 0 等于 limit；只有多目标且该值小于 limit 时才截断，并在 warnings 点名 |
| output | str | inline | inline / file | file 时按游标翻页取满再落盘，忽略本次 limit |
| format | str | csv | csv / json / ndjson / md / text / html | 落盘格式；html 仍是旧表格渲染 |
| include_media | bool | true | 真/假 | 返回条数超过 50 时自动跳过媒体提取并给 warning |
| output_dir | str | 空 | 目录 | 落盘目录，留空写本进程 exports/run-* |
| extract_media | str | 空 | 空 / auto / 绝对目录 | 把图片、语音、视频原件另存 |

types 合法值（valid_types()，共 18 个）：text、image、voice、video、emoticon、file、link、mini_program、quote、chat_record、channels、transfer、red_packet、location、card、voip、system、revoked。system 与 revoked 互为别名；file 实际映射 app:file，以此类推。

输出：

| 字段 | 含义 |
|---|---|
| ok、detail | 基本信封 |
| total | 命中总数，按游标过滤前统计；有 per_target_limit 截断时仍把这些行算进去 |
| returned、has_more、next | 本页条数与游标；has_more 按游标过滤后的剩余算 |
| per_target_limit | 多目标时回显生效值，单目标为 null |
| default_window_days | 30 表示走了默认时间窗，0 表示按目标或日期截取 |
| chat | 本页只涉及一个会话时给会话名，多会话为空串 |
| self | {id, nickname, alias, note} |
| senders | 仅 full 与 raw；键是 wxid，值含 name、nickname、alias、friend |
| messages[] | 见下 |
| unresolved | 目标解析不到或没有分表 |
| hints / warnings / media_missing / media_inline / media_extract / file_export / export | 条件字段 |

message 字段（三档）：

| 字段 | lite | full | raw | 说明 |
|---|---|---|---|---|
| id | 有 | 有 | 有 | 会话内 local_id |
| time | 有 | 有 | 有 | YYYY-MM-DD HH:MM:SS |
| from | 有 | 有 | 有 | 显示名；本人固定「我」；系统消息为空 |
| from_unknown | 条件 | 条件 | 条件 | 只有非系统消息解析不到发送者时出现；系统消息本就没有发送者，不标（668bae0） |
| text | 有 | 有 | 有 | 自足正文，见下表 |
| media | 条件 | 条件 | 条件 | 非纯文本才有；lite 只保留少量键 |
| quote | 条件 | 条件 | 条件 | 引用消息才有：{from, text} |
| chat | 多会话时 | 无 | 无 | lite 每行的会话名，本页跨多个会话才出现 |
| sender_id | 无 | 有 | 有 | 发送者 wxid，系统消息为空 |
| type | 无 | 有 | 有 | 用户可见类型；49 类统一是 app，具体类别看 subtype |
| subtype | 无 | 仅 app 有 | 仅 app 有 | file、link、transfer、red_packet、quote、chat_record、mini_program、channels、music、sticker、location、card、app、app_NN |
| chat_id / chat_name | 无 | 有 | 有 | 会话 id 与显示名 |
| local_type / raw / db | 无 | 无 | 有 | 原始整数、原始 XML、分库文件名 |

media 按 kind（full 档字段；lite 只保留 kind、name、title、url、duration、amount、text、missing_reason 里非空的键）：

|---|---|

MCP 返回形态：没有内联图片时返回单个 JSON 字符串；有内联图片时返回内容块数组，第一个块是同一份 JSON 字符串，后面每张图一个 Image 块。

分页与导出：

- 游标由 ts、db、tbl、local_id 四段拼成，实测 page2 与 page1 不重复，total 保持全量命中数。
- output=file 用同一套参数翻页取满：每页 1000 条，最多 200 页或 200000 行，超过标 is_partial=true；导出的范围由 targets、日期、types、keyword 决定，本次 limit 被忽略（实测 limit=3 仍导出某群 39 页，每页最多 1000 条）。
- 导出为 text/md 时按会话分节、一行一条，多行正文用两空格缩进续写，不用表格；csv 固定列并剔掉全空列，media 与 quote 压成短 JSON（实测：合成三行数据只保留 6 列）。text 格式落盘后缀是 .text，不是 .txt。

## 5 relations

输入：

| 参数 | 类型 | 默认 | 取值 | 行为 |
|---|---|---|---|---|
| kind | str | 必填 | group_members / common_groups / person_activity / activity | 写错只回旧式 error |
| subject | str | 必填 | 群名 / 群 id / 人名 / wxid | 只接受 exact 或 contains 命中且 kind 对得上（群要 group，人要 person），否则给 candidates |
| targets | list | null | 群清单 | 只给 person_activity 用；全部解析失败时静默按全部群统计 |
| since_date / until_date | str | 空 | YYYY-MM-DD | 四类都接受，但 group_members 与 common_groups 实际不按时间过滤 |
| limit | int | 500 | 正整数 | group_members、common_groups、person_activity 用它截断；activity 不受它约束 |
| output / output_dir / format | | inline / 空 / json | file 时落盘 | 同通用约定 |

四类输出：

| kind | 顶层字段 |
|---|---|
| group_members | ok、kind、group{id,name,owner_id}、total、returned、has_more、next（恒 null）、members[]、data_until、refresh |
| common_groups | ok、kind、person{id,name}、total、returned、has_more、next（恒 null）、groups[{id,name,messages}]、basis、data_until、refresh |
| person_activity | ok、kind、person{id,name}、scope{targets}、total、messages_total、returned、has_more、next（恒 null）、groups[{id,name,messages,last_at}]、basis、data_until、refresh |
| activity | ok、kind、chat{id,name}、total、by_day[{day,count}]、by_hour[24 项]、by_type{类型: 数}、top_senders[{name,messages}]（前 10）、basis、data_until、refresh；没有 returned、has_more、next |

member 字段：id、name、remark、nickname、alias、relation（好友 / 非好友）、signature、gender、region。

实测（activity 节选）：

